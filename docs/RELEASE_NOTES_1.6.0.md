# Native Agent Harness 1.6.0

- **Старт сессии.** Обработчик SessionStart формирует короткий начальный контекст.
  Продолжение связывает сохранённую цель и ограничения с текущим каталогом и
  квитанциями сессии.
- **Проверяемое исполнение.** Проверка плана, работа узлов, интеграция и итоговое
  ревью сверяют актуальность одного кандидата. Восстановление использует прежние
  дедлайны и счётчики и учитывает уже зафиксированные вызовы.
- **Совместимость с Windows.** Подготовка сравнивает физическую идентичность
  каталогов, включая короткие имена 8.3. Экспорт Git сохраняет исходные байты
  при точном преобразовании LF в CRLF. Пакеты с длинными путями и разными дисками
  используют компактные адреса в прежнем лимите.
- **Журнал и восстановление.** Процессы согласуют захват байтов журнала и
  проекций. Кэш подтверждает байты перед использованием, а публикация ремонта
  сверяет маркер восстановления. Форматы сохранённых точек и квитанций совместимы.
- **Нативное ядро.** Сборки Windows и Linux содержат Rust snapshot и RepoMap.
  Для Linux доступен опциональный потоковый LSP. Протокол вызовов v1 сохраняется,
  а явный запрос v2 сообщает возможности.

Для обновления используйте полный архив с нативными сборками Windows и Linux
и действующие каталоги профиля и состояния. После установки откройте новый
процесс Codex и проверьте обработчик SessionStart в `/hooks`. [Установка](../SETUP_RU.md).

К выпуску относятся архив, его контрольная сумма и `VERIFICATION.json` с
коммитом и результатами проверок. [История изменений](../CHANGELOG.md).
