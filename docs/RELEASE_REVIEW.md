Поставка общего назначения собрана из актуального рабочего дерева 1.0.1,
включая незакоммиченные изменения установленной настройки. Исходный checkout
и текущая пользовательская установка не изменялись. Исходные SHA256 до экспортных
изменений перечислены в `provenance/source-snapshot.json`.

Native probe выполнен установленным `codex-cli 0.166.0-alpha.5.1` в отдельном
профиле и пустом проекте. Он не обращался к LLM и не доказывает поведение desktop
или полноценной агентной задачи. Собственные runtime-файлы и system skills,
которые Codex создаёт в новом профиле, не принадлежат harness и не удаляются.

Исправления при подготовке: расширение транзакционной установки на bundled
skills; конфликт с чужими skills без перезаписи; блокировка обновления при
исчезновении прежнего owned resource; regression tests; canonical TEMP paths
в Windows fixture; удаление project-specific shortcut; правильный ключ
`agents.default_subagent_reasoning_effort` в справочном профиле.

Независимый reviewer рассмотрел сценарии создания локального Markdown skill,
постороннего запроса перевода и отсутствующего GitHub plugin. Это статическая
проверка инструкций, не поведенческая квалификация LLM. Открытых подтверждённых
замечаний после repair нет. Raw logs, manifests и полный отчёт reviewer
сохранены приватно вне репозитория.

## Границы подтверждения

- CI для Windows/Ubuntu и Python 3.11/3.13 задан в `.github/workflows/check.yml`;
  фактический результат смотрите в Actions для нужного commit, а не по наличию YAML.
- Arch Linux, поведение в hosted ChatGPT Work, hot reload старых чатов, полный
  spawn/repair/recovery в новом профиле и интеграции внешних аккаунтов не проверялись.
- Secret scan ограничен известными patterns и проверенным набором файлов;
  это не доказательство отсутствия любого возможного секрета.
- Системные/сторонние skills, токены, auth, приватные runs, machine overlay,
  история Git исходника и проектные адаптеры в поставку не включены.
- Чужие upstream решения изучаются по исходникам отдельно; их код автоматически
  не устанавливается, а их заявленная совместимость не считается нашим тестом.
