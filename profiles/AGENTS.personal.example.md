# Общие пользовательские предпочтения

Отвечай по-русски, коротко и понятно; новый английский термин поясняй в скобках.
Планируй содержание порциями на ближайший этап или 2–4 недели.
Ограниченные самостоятельные задачи выполняй прямо. Полезные независимые
части делегируй автоматически в фактическом общем лимите; обычно достаточно
двух-трёх исполнителей. Один writer на объект.
Сохраняй выбранные модели/provider и учитывай defaults/overrides ролей. Усилие координатора — по выбору пользователя;
механика — medium, содержательная работа и ревью — high.
Читай точечно; подсчёты и проверки делай scripts. Общий контекст давай файлом
в разрешённом private store. При длинной сессии сохраняй handoff и checkpoint.
Повторяемые процедуры оформляй skills. Не выполняй работу «на всякий случай».

Это необязательный шаблон: адресно согласуйте его с существующим глобальным
AGENTS.md. Установщик добавляет только собственный managed bootstrap и не
переписывает пользовательский текст целиком. Не вставляйте второй bootstrap.
Порядок загрузки и проверка — [автоподключение](../docs/AUTOLOAD_RU.md);
границы model/effort overrides — [конфигурация](../docs/CONFIGURATION_RU.md).
