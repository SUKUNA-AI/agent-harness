# Исследование

Определи вопросы, период и достаточный результат. Собери первичные источники, проверь доступные тексты и привязку выводов, даты и противоречия. Раздели наблюдаемый факт, вывод и unknown. Для содержательного обзора по умолчанию распредели независимые вопросы между 2–3 native владельцами в общей наблюдаемой ёмкости; root сверяет источники и интегрирует выводы. При неделимости/нехватке ёмкости объясни последовательный режим одной строкой; не создавай фиктивный Git repository. Сохраняй материалы только при разрешении и в правильной границе конфиденциальности. Evidence типа source содержит URL/идентичность, дату доступа, конкретный поддержанный вывод и просмотренный фрагмент/артефакт. Root проверяет поддержку выводов, а не только доступность URL. Итог — ответ с источниками и пределами, без самовольного изменения внешних объектов.
