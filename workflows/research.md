# Исследование

Определи вопросы, период и достаточный результат. Собери первичные источники, проверь доступные тексты и привязку выводов, даты и противоречия. Раздели наблюдаемый факт, вывод и unknown. Делегируй независимые вопросы лишь при пользе; не создавай фиктивный Git repository. Сохраняй материалы только при разрешении и в правильной границе конфиденциальности. Evidence типа source содержит URL/идентичность, дату доступа, конкретный поддержанный вывод и просмотренный фрагмент/артефакт. Root проверяет поддержку выводов, а не только доступность URL. Итог — ответ с источниками и пределами, без самовольного изменения внешних объектов.
