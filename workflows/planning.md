# План и спецификация

Зафиксируй цель, ограничения, входы, зависимости, конкретные шаги, риски и применимую приёмку. Разреши значимую неоднозначность доступными данными; уточни только блокирующее. Проверь исполнимость, полноту и отсутствие неразрешённого расширения. Заверши согласованным планом/спецификацией. Запрос составить план не разрешает установку, исправление или deployment.

Для содержательной спецификации root сам готовит постановку и по умолчанию поручает независимые варианты/риски 2–3 native владельцам в общей ёмкости; при неделимости работает последовательно. Используй общий контекст и `harness-orchestrate`; пользователь не обязан выбирать роли или заполнять JSON. Результат этого workflow остаётся планом, не исполнением.
