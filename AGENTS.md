# Разработка общего Agent Harness

Отвечай по-русски, коротко и конкретно. Это переносимый пакет общего назначения.
Политика: `policies/global.md`; установки: `src/agent_harness/installation.py`.
Не добавляй сюда историю чатов, проектные данные, auth, токены, machine overlay,
логи выполнения или абсолютные пути конкретного компьютера.
Сохраняй чужие изменения. Один writer на checkout. До 2–3 полезных потоков;
каждый Git writer работает в отдельном worktree. Для простых задач агенты не нужны.
Выбранные model/provider сохраняются; учитывай defaults/overrides дочерних ролей.
Механика — medium, реализация/ревью — high. Порог auto compact 500000 сохраняй.
Не меняй безопасность, модель и усилие координатора под видом установки.
Общие правила и skills должны работать без подключённых внешних сервисов.
Изменения установщика проверяй в изолированных homes, включая конфликт,
повторную установку и rollback. Запусти `python tools/release_check.py` и
`python tools/run_tests.py`. Приватные evidence находятся за пределами репозитория.
