# Предметный адаптер

Новый адаптер задаёт контекст применимости, авторитетные источники/даты, терминологию, разрешённые операции и результаты, входы/версии, проверки, риски неверной интерпретации и доступные инструменты. Он не меняет полномочия, безопасность или core. Абсолютные пути машины размещаются в machine overlay, приватные данные — в отдельном run store.

Для C++/CUDA укажи compiler/toolkit/GPU/driver, correctness oracle, dtype/tolerance, baseline, dataset, warmup/repeats и эксклюзивность нагрузки. Для исследования — источники, период и отличия фактов/выводов. Для обучения — уровень ученика и выбранный режим помощи. Для документов — оригинал, формат, требования полноты и просмотренное представление. Неподтверждённые возможности остаются unverified.
