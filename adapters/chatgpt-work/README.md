# ChatGPT Work: граница подключения

`policies/global.md`, workflows и роли описывают переносимый протокол. Эта локальная установка пишет CODEX_HOME и персональный skill на компьютере; она **не подключает** их к hosted ChatGPT Work. Рабочего hosted adapter и подтверждённого автоматического применения в Work эта поставка не заявляет.

Для отдельного подключения сначала подтвердить штатный источник постоянных инструкций hosted клиента, permissions и доступные native agents; затем выполнить новую приёмку. Нельзя получать секреты, менять provider, подменять backend локальным CLI или объявлять локальный config действующим в Work. Недоступность второго backend не блокирует приёмку подтверждённого локального Codex.
